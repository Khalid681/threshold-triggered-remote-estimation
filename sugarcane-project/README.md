# Threshold-triggered remote estimation under packet loss

This project asks how often a sensor needs to send an update for a remote receiver to track temperature and soil moisture when some packets are lost. It replays measurements from 12 agricultural sensors and simulates a sender that transmits when a reading differs enough from its reference value. The analysis compares approaches that hold the last received reading or predict how it changes between updates.

The experiments measure estimation error, communication rate, and age of information (AoI), the time since the latest received reading was taken. Packet loss and acknowledgments are simulated. Gaps between recorded measurements are used to identify segments in the dataset.

## Research questions

1. How do loss and threshold policies trade estimation accuracy against communication rate, age of information (AoI), and freshness?
2. When does receiver-side prediction help or hurt under identical received packets?
3. Do improvements generalize across sensors and survive independent validation, rather than only across channel seeds?

Hold, full global drift, validation-selected weighted drift and validation-selected local linear prediction are evaluated without changing transmissions. A negative result for prediction is a valid outcome.

Attribute the dataset authors and identify this cleaned derivative when publishing.

## Model and chronological evaluation

Within each eligible node-signal segment (at least 100 records), the first 60% train, next 20% validate and final 20% test, with strict timestamp separation. Training alone sets the threshold scale (1.4826 times increment MAD, falling back to increment standard deviation and a 1e-6 floor), least-squares global drift, and the local slope clipping bound (95th percentile of absolute adjacent training slopes). Validation alone selects a beta from the configured grid separately for each segment, threshold, loss and predictor; ties choose the smaller beta. Changing test values cannot affect calibration.

Each validation or test window initializes both endpoints with its first measurement at no packet cost; initial accuracy is included. This common warm start favors every method equally but makes very short windows optimistic. The receiver holds the last delivered value, extrapolates the global drift, or extrapolates the slope between its two most recent successfully received values (including initialization). Local slope is zero before the second received value, clipped to the training bound and multiplied by its independently validation-selected beta. No unreceived value is used in prediction. Predictions themselves are not clipped to a physical range; long extrapolation can still be poor, which is reported honestly.

A transmission is attempted when the absolute difference from the sender reference reaches the training-derived threshold. ACK means instantaneous, reliable feedback: only delivery updates the sender reference. No-ACK updates it on every attempt. After a failed ACK attempt, later above-threshold observations are counted as retry attempts until successful delivery; these can contain newer values, so this is an outstanding-update burden, not literal retransmission of the same packet. No-ACK has zero retry attempts and undefined retry fraction.

Bernoulli loss is the primary model. The Gilbert-Elliott option uses a perfect good state and an erasing bad state. For target stationary loss p and mean bad-state length L, P(B->G)=1/L and P(G->B)=p/((1-p)L). Invalid probabilities are rejected. State starts in its stationary distribution and advances at **every observation**, including no-attempt observations. L=5 is measured in observation slots, not minutes or attempted packets; irregular gaps do not create extra hidden transitions. Consequently, stationary loss over observations need not equal loss conditional on threshold attempts. Report measured PDR alongside target loss.

Channel seeds use SHA-256 over base seed, phase, node, signal, segment, threshold multiplier, loss, feedback and channel model. Calibration and evaluation base seeds are disjoint. All estimators consume exactly one shared reception trace per condition, with its digest saved in each linked table. Loss-free evaluation and calibration use one seed because their outcomes are deterministic. Nonzero delivery delay raises an explicit error; arrival events are not approximated.

## Exact metric definitions

Accuracy is sampled at observation times after a possible zero-delay reception: MSE, MAE, RMSE and signed bias. NMSE=MSE/test variance and NRMSE=RMSE/test standard deviation, using population variance. Variance <=1e-12 yields undefined normalized metrics, with an explicit constant-trace flag and undefined counts; these are excluded from normalized means, not replaced by zero. Raw MSE still includes these runs.

Over [first test timestamp, last test timestamp], age grows linearly from each post-reception age A_i. Its exact interval area is A_i*dt + dt^2/2. Mean AoI is total area divided by total elapsed time. Peak AoI includes each age immediately before the next boundary. For deadline D, violation duration is clip(dt-(D-A_i),0,dt), so crossing inside an interval is counted exactly. Endpoint equality has zero duration. Sample mean and sample 95th-percentile AoI are separately named; they are not continuous-time means or percentiles. No tail beyond the last observation is invented.

For times [0,10,20,30], latest generation [0,0,20,20], D=5, mean AoI=25/3, peak=20, violation=2/3, sample mean=5.

Communication rates are attempts or deliveries divided by elapsed minutes, and also reported per eligible observation (N-1). Per-run PDR is delivered/attempted, undefined with zero attempts. Aggregate PDR is **sum delivered / sum attempted**, never a mean of run ratios. Summaries include packet totals, zero-attempt runs and retry burden. AoI, communication and freshness are channel-policy outcomes, not estimator-specific curves.

The random-walk baseline intentionally retains its separate discrete convention (age resets to one slot): update rate=1/T^2, mean AoI=(5T^2+1)/6, MSE=(T^2-1)/6 for p=q=0.5. Its 95% intervals describe 20 increment-block Monte Carlo variability with 10,000 bootstrap draws, not agricultural node uncertainty. Each block reinitializes the threshold policy, causing a small finite-block boundary effect.

## Statistical design

Accuracy keys are node, signal, segment, threshold, loss, seed, feedback and channel; **no freshness deadline** enters accuracy pairing. The legacy analysis importer removes only consistent duplicate deadline copies, rejects conflicting duplicate MSEs, and collapses identical zero-loss seeds. New raw tables never contain deadline copies.

Within each signal/threshold/loss condition, first average seeds within segment, then segments within node. Nodes receive equal weight, irrespective of segment or seed counts. The reported mean MSE and mean paired difference (candidate minus hold) use this hierarchy. Negative differences favor prediction. Aggregate relative improvement is 100*(node-balanced mean hold MSE - node-balanced mean candidate MSE)/mean hold MSE, undefined when its denominator <=1e-12. Individual percentage improvements are never averaged.

Confidence intervals are percentile intervals from **10,000 resamples of independent nodes**, fixed seed 8675309. With fewer than two valid nodes the interval is undefined. These intervals describe between-node uncertainty, conditional on the observed data and selected calibration. They do not treat Monte Carlo seeds or segments as independent sensors. The exact two-sided sign-flip test enumerates all 2^12 signs for 12 node effects; it assumes sign exchangeability under the null. More than 20 nodes is rejected explicitly. Benjamini-Hochberg q-values use one conservative family covering every signal, candidate, threshold and loss comparison in a run. Comparing separate run families requires a further planned multiplicity strategy.

Reports include unique pairs, nodes, node-segments, seed counts, all three original estimator means, candidate means, mean and median differences, aggregate relative improvement, descriptive unique-pair win/tie/loss fractions (absolute MSE tie tolerance 1e-12), clustered intervals, p and q values. Median paired differences and pooled fractions remain descriptive; the inferential mean is node-balanced. Within-segment seed SD and pooled pair SD explicitly describe Monte Carlo/trace variation. Loss-free within-segment seed SD is undefined.

Raw MSE can be dominated by high-variance nodes even after equal node weighting; normalized figures complement it. Constant traces can change the set of nodes contributing to a normalized figure; valid-node and missing-run counts disclose this.

## Interpretation limits

Twelve sensors at one site and one recording period do not represent independent farms or seasons. Nearby sensors can be spatially correlated, which node clustering alone cannot remove. Calibration is segment-specific and assumes training and validation are available before the held-out period. Threshold comparisons use independently derived channel streams, whereas estimators within each condition are strictly paired. No simulated ACK/burst/no-ACK result establishes real network performance. No delay experiment is supported. Inspect effect direction, normalized errors, sensor heterogeneity and uncertainty before making any claim of improvement.
